Game Developer

Hi! I'm Brendan, an aspiring game developer that's passionate about creating stories that others can experience and enjoy. My introduction to game development was in 2014 where I began developing Minecraft mods which introduced me to Java and programming in genral, then in 2015 I started experimenting with game engines such as Unreal Engine 4 and Unity which taught me concepts such as Object-Oriented Programming, Detail-Oriented Design and Entity Component Systems. Since then, I've taken on personal projects such as computer graphics programming with Vulkan as well as receiving a formal education in game design, which has allowed me to streamline and organize my project management process. With the skills I've gained over the years, I'm looking forward to creating games that people can enjoy.
